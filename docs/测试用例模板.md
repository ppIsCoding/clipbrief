## 四、5 分钟冒烟清单

每次合并后跑一遍，任何一步失败就不要继续合并：

1. 打开首页，输入 B站链接，能解析出标题和封面
2. 选 360p/合并档，能下载并播放
3. 登录后点总结，摘要能逐字出现
4. 总结完成后，导图/字幕能打开
