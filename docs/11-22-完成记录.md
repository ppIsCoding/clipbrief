## 二、设计

- 统一色板：深海军蓝 `#0B1B3A`、品牌蓝 `#1777FF`、浅底 `#F4F8FF`、青色 `#7DD3FC`
- 字体：微软雅黑；数字用 Arial，便于投影
- 深色封面/结尾 + 浅色内容页，形成“三明治”结构
- 视觉母题：圆角卡片 + 左上角英文 kicker + 右下角页码
- 每页至少一个视觉元素：数据卡、流程图、对照条、真实截图或表格
- 不使用标题下划线，避免“AI 味”

## 六、收尾修复

| 问题 | 处理 |
| --- | --- |
| 非 B站链接的 query 被整体裁掉，YouTube `?v=` 会失效 | `normalize_video_url` 只处理 B站，其他平台原样返回 |
| 配额按 UTC 跨天，北京时间早上 8 点才重置 | 改为 `Asia/Shanghai`，可用 `QUOTA_TIMEZONE` 覆盖；Windows 缺 tzdata 时用固定 +08:00 |
| 邮箱大小写可能注册出两个账号 | 注册/登录统一 `strip().lower()` |
