## 二、设计

- 16:9，13.333×7.5；暖白纸感 `#F4F1EA`、墨黑 `#121417`、钴蓝 `#1B3BFF`、警示橙 `#FF5A36`
- 字体：Noto Sans SC 标题、微软雅黑正文、Bahnschrift 数字、Consolas 标签
- 左侧 0.75" 网格、细线分隔、无圆角卡片和重阴影；深色章节页制造节奏
- 视觉母题：大数字、整块钴蓝、浏览器白框截图、编号表、页脚 `01 / 18`
- 参考了 SlidesCarnival 的 tech / pitch deck 版式逻辑，但没有套 stock 照片和英文占位
- 每页写入 1–2 句演讲备注，排练时用 PowerPoint 演示者视图

## 四、视觉 QA

用 LibreOffice 转 PDF、pdftoppm 逐页转图，再逐页看全尺寸渲染，修了：

| 问题 | 处理 |
| --- | --- |
| 封面页码落在深色块上，灰字看不清 | 页码单独用浅色 |
| 封面截图说明落在纸色区却用白字 | 改成墨色 |
| P2 章节页页脚误写“功能实现” | 传入“优化记录” |
| 组件树第二行连线穿框 | 改成组件清单 |
| 深色页上的大号钴蓝字对比不足 | 收尾页改用 `#7C8CFF` |
| 第 2 / 5 / 7 / 10 页下半页过空 | 补结论句或说明线 |
| 第 12 页浮动标签孤立 | 删除 |
| 表格贴页脚、行高不一致 | 统一行高与上边距 |
| 内容按模块而不是按功能组织，留白多 | PPT1 重排为 18 页，每个功能一页：输入/流程/结果/边界 + 证据 |
| 文案口号感重 | 标题改成功能名，结论改成具体数字和事实 |

## 六、收尾修复

| 问题 | 处理 |
| --- | --- |
| 非 B站链接的 query 被整体裁掉，YouTube `?v=` 会失效 | `normalize_video_url` 只处理 B站，其他平台原样返回 |
| 配额按 UTC 跨天，北京时间早上 8 点才重置 | 改为 `Asia/Shanghai`，可用 `QUOTA_TIMEZONE` 覆盖；Windows 缺 tzdata 时用固定 +08:00 |
| 邮箱大小写可能注册出两个账号 | 注册/登录统一 `strip().lower()` |

新增 `backend/tests/`，17 个标准库 `unittest` 用例：
