## 一、模型配置

`backend/summarizer.py` 不再写死 DeepSeek 官方地址，改为三个环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `LLM_API_KEY` | 空 | 必填，兼容旧的 `DEEPSEEK_API_KEY` |
| `LLM_BASE_URL` | `https://api.deepseek.com` | OpenAI 兼容接口地址 |
| `LLM_MODEL` | `deepseek-chat` | 模型 ID |

使用 OpenCode Go：

```
LLM_BASE_URL=https://opencode.ai/inference/go/openai/v1
LLM_MODEL=deepseek-v4.1-flash
```

请求会带 `User-Agent: clipbrief/1.0` 和 `x-opencode-session`，符合 Go 对客户端的要求。

> 本机验证时通过进程环境变量注入 Key，仓库和文档里不保存密钥；换机器时复制 `.env.example` 为 `.env` 填自己的值。
