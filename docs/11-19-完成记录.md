## 一、SEO / GEO

### 修掉一个真实错误

## 二、URL 安全校验（SSRF）

新增 `backend/security.py`：

- 只允许 `http/https`
- 解析域名，拒绝私网、回环、链路本地、保留、组播、未指定地址
- 拒绝 `localhost`、`*.localhost`、`*.local`
- 覆盖接口：`/api/parse`、`/api/download`、`/api/download/start`、`/api/direct-url`、`/api/proxy/thumbnail`、`/api/summarize`、`/api/chat`

错误统一为：

```json
{ "detail": { "success": false, "error": "不支持内网或本地地址" } }
```

### 实测

| 输入 | 结果 |
| --- | --- |
| `http://127.0.0.1:8000/api/health` | 400 不支持内网或本地地址 |
| `http://localhost:5173/` | 400 不支持内网或本地地址 |
| `http://169.254.169.254/latest/meta-data/` | 400 不支持内网或本地地址 |
| `file:///etc/passwd` | 400 仅支持 http/https 视频链接 |
| 缩略图代理传内网地址 | 400 |
| `/api/summarize` 传内网地址 | SSE `error` 事件，不进入字幕提取 |
| 正常 B站链接 | 200，返回 5 档格式 |
