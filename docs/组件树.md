# 前端组件树

> 当前基于参考实现裁剪：去掉了支付/定价组件，保留下载、总结、登录和 SEO 内容。

## 结构

```
App.vue
├─ AppHeader.vue          标题、导航、登录状态、用户菜单
├─ HeroSection.vue        首屏标题 + 链接输入 + 解析按钮
├─ VideoResult.vue        封面、标题、时长、清晰度列表、下载/总结按钮
├─ VideoSummary.vue       总结面板（摘要 / 字幕 / 导图 / 问答 四个 tab）
├─ FeatureSection.vue     功能特性
├─ HowToSection.vue       使用教程（SEO/GEO 内容）
├─ ComparisonSection.vue  工具对比（SEO/GEO 内容）
├─ PlatformSection.vue    支持平台
├─ AppFooter.vue          页脚、使用声明
└─ AuthModal.vue          登录/注册弹窗
```

## 数据流

```
App.vue
  ├─ currentUser                 ← api/auth.js
  ├─ videoData / currentUrl      ← api/video.js: parseVideo
  ├─ summaryKey                  ← 点「生成总结」时 +1，触发 VideoSummary 重新请求
  └─ 通过 props 传给子组件，通过 emit 回传操作
```

`VideoSummary` 自己维护总结状态：

- `subtitleData`：`subtitle` 事件
- `summaryText`：`summary` 事件逐段拼接
- `mindmapMarkdown`：`mindmap` 事件
- `quotaInfo`：`quota` 事件
- 错误：`error` 事件，`need_login` 时通知父组件打开登录框

## 接口对应

| 组件 | 接口 |
| --- | --- |
| HeroSection | `POST /api/parse`（由 App 调用） |
| VideoResult | `POST /api/download`、`GET /api/proxy/thumbnail` |
| VideoSummary | `POST /api/summarize`、`POST /api/chat` |
| AuthModal | `POST /api/auth/register`、`POST /api/auth/login` |
| AppHeader | `GET /api/auth/me` |

## 约定

- 组件用 `<script setup>`，props 显式声明类型和默认值
- 每个组件自己处理加载态、空态、错误态
- 不引入 UI 组件库，Tailwind 手写
- SSE 解析统一放在 `src/api/summarize.js`，组件只处理事件回调
