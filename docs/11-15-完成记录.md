## 二、本轮改动

### 1. 后端错误提示中文化

`backend/main.py` 增加 `friendly_error()`，把 yt-dlp 的英文异常映射成中文：

| 原始异常关键词 | 返回给前端 |
| --- | --- |
| `Unsupported URL` / `is not a valid URL` | 不支持的平台或链接，请换一个视频地址 |
| `Unable to download webpage` / `HTTP Error 404` | 无法访问该链接，请确认地址有效或换一个平台 |
| `HTTP Error 403` | 该平台拒绝了请求，请稍后重试或配置 cookies |
| `Unable to download API page` / `Connection` / `timed out` | 当前网络无法访问该平台，请检查网络后重试 |
| `Private video` / `login required` / `sign in` | 该视频需要登录或没有访问权限 |
| `Requested format is not available` | 所选清晰度不可用，请重新解析后再选 |

`/api/parse`、`/api/download`、`/api/direct-url` 都走这套映射；未命中的异常仍保留前 200 个字符，方便排查。

### 2. 前端错误提示改为页面内展示

`frontend/src/App.vue`：

- 删除解析/下载失败时的 `alert()`，改为输入框下方的红色提示条
- 提示条带「重试」和关闭按钮；重试会重新执行上一次解析或下载
- 下载失败时优先读取后端 `detail.error`，不再只显示 `Request failed with status code 400`

实测：解析 `https://example.com/foo` 后页面出现提示，无原生弹窗；点「重试」可再次请求，点关闭可隐藏。

### 3. 移动端修复
