## 三、优化前已知问题（作为对照）

| 问题 | 优化前表现 | 现在 |
| --- | --- | --- |
| 游客解析后弹登录框 | 遮罩挡住下载按钮，像“点不动” | 内联提示，不遮挡 |
| 下载文件串档 | 先下 1080p 再下 360p 仍拿到 1080p | uuid 唯一命名 + 响应后删除 |
| AV1 兼容 | Windows 自带播放器打不开 | 优先 H.264 |
| 进度跳变 | 合并档从 99% 掉回 20% | 预解析分母，单调到 100% |
| 错误提示 | 原生 `alert` + 英文异常 | 页面内中文提示 + 重试 |
| 导出下载被取消 | 立即回收 blob URL | 直链下载，不再走 blob |
| 导图 NaN | 隐藏 Tab 时 `translate(NaN,NaN)` | 切 Tab 再渲染 |
| SEO 结构化数据 | HowTo JSON 引号错误，解析失败 | 已修正，3 段全部合法 |

## 四、测量方法

1. 首屏：`localhost:5173` 加载完成，1440×1000。
2. 解析：点击「解析视频」到「选择清晰度和格式」出现。
3. 下载：点击「立即下载」到浏览器 `download` 事件。
4. 总结：点击解析到 `.summary-prose` 出现（首 token），到配额文案出现（完成）。
5. 问答：POST `/api/chat` 到收到 `done`。

## 五、给第二场汇报的结论

- 主链路已经可用：解析 2 秒级、下载可用、总结 1 分钟内出首段。
- 优化重点不是“更快”，而是“不误导、不中断”：进度、错误、兼容、导出。
- 长视频（8 分钟以上）总结耗时 1 分钟以上，演示建议用 2–3 分钟视频。
