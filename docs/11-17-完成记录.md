## 一、思维导图 NaN 修复

现象：切到「思维导图」前后，控制台报：

```
<g> attribute transform: Expected number, "translate(NaN,NaN) scale(…"
```

原因：导图 Tab 用 `v-show` 隐藏，隐藏时 SVG 宽高都是 0，markmap 的 `autoFit` 除零算出 NaN。

处理：

- 渲染前检查 SVG 实际宽高，为 0 时先不画
- 监听 `activeTab`，切到导图时再渲染；已经画过的调用 `fit()` 重新适配
- 重复渲染前销毁旧 markmap 实例，组件卸载时也销毁

实测：切到导图 Tab 后正常显示节点，控制台无报错，SVG 里没有 `NaN`。

## 二、AI 总结错误状态

- 去掉总结失败时的 `alert()`，改为总结面板内红色提示 + 「重新总结」按钮
- 新增 `AbortController`：重新总结或切换视频时中止上一条 SSE，避免两段摘要拼在一起
- 组件卸载时中止请求
- SSE 流没有收到 `done` 就结束（断线/服务端异常）时，提示「总结连接中断，请重试」，不再一直转圈

Mock 增加失败哨兵：URL 里带 `fail` 时返回 `error` 事件，方便演示和回归。

实测：`https://example.com/fail-video` 显示「模拟：该视频没有可用字幕」，点「重新总结」可再次请求，全程无原生弹窗。

## 三、导出产物

### 修复

`triggerDownload()` 之前创建 blob URL 后立刻 `revokeObjectURL`，部分浏览器会把下载取消，表现为点了没反应。改为 1 秒后再回收。

### 实测（Mock 数据）

| 产物 | 结果 |
| --- | --- |
| SRT | 208 字节起，`1 / 00:00:00,000 --> 00:00:03,200 / 文本`，UTF-8 正常 |
| VTT | `WEBVTT` 头 + 时间轴，UTF-8 正常 |
| TXT | 两段字幕按行拼接 |
| SVG | 15,842 字符，含节点文字，无 `NaN` |
| PNG | 4476×2347，494 KB，可正常打开 |
