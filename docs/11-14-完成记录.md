- 下载完成后 `backend/downloads/` 自动清空

### 修掉的两个问题

**1. 下载文件串档（P1）**

- 现象：先下过 1080p 后，再选 360p 下载，拿到的仍是 1080p 文件
- 原因：`outtmpl` 只用标题命名，临时目录里已有同名文件时 yt-dlp 直接跳过下载，把旧文件返回
- 修复：每次下载用 `uuid` 生成唯一文件名；响应结束后用 `BackgroundTask` 删除临时文件
- 验证：清空目录后先下 1080p、再下 360p，两次文件大小和分辨率都正确

**2. 游客解析后自动弹登录框（P2，BUG-001）**

- 现象：解析成功后登录弹窗立刻盖住页面，用户以为"下载按钮点不动"
- 原因：解析后自动触发总结，未登录返回 `need_login`，前端直接打开登录框
- 修复：未登录时不再自动弹窗，总结面板显示"登录后可使用 AI 总结 + 去登录"按钮；登录成功后自动开始总结
- 验证：解析后 `登录账号` 弹窗不出现，登录提示可见，下载按钮可正常点击

### B站 Cookie 支持

`downloader.py` 增加可选配置：

```python
if cookies_file := os.getenv("COOKIES_FILE"):
    ydl_opts["cookiefile"] = cookies_file
```

`.env.example` 增加 `COOKIES_FILE=`。不配置时保持匿名下载；需要高码率/受限视频时填 `cookies.txt` 路径。
